## Navbar

**Class:** `.navbar` / `#navbar`
**Used by:** All pages

### Structure
```html
<header class="navbar" id="navbar">
  <div class="nav-inner">
    <a class="logo">WEVOX<span class="dot">.</span></a>
    <nav class="nav-links">...</nav>
    <div> <!-- right slot: auth button + hamburger --> </div>
  </div>
</header>
```

### Behaviour
- Fixed to top of viewport (`position: fixed; top: 0`)
- Adds `.scrolled` class (box-shadow) when `window.scrollY > 50`
- On mobile (`≤768px`): `.nav-links` hidden, `.hamburger` shown
- Height: ~57px desktop, ~52px mobile

### Responsive
| Breakpoint | Behaviour |
|---|---|
| Desktop | Full nav links visible |
| ≤768px | Nav links hidden, hamburger shown |

## Mobile Overlay

**Class:** `.mobile-overlay` / `#mobileOverlay`
**Used by:** All pages

### Structure
```html
<div class="mobile-overlay" id="mobileOverlay" aria-hidden="true">
  <button class="close">✕</button>
  <a href="...">Link</a>
  ...
</div>
```

### Behaviour
- Full-screen dark overlay (`background: var(--bg-dark)`)
- Slides in from right (`transform: translateX(100%)` → `translateX(0)`)
- Opened by hamburger click, closed by close button or link click
- Sets `document.body.style.overflow = 'hidden'` when open
- Large Literata font links for easy touch targets

## Hero / Identity Strip

**Class:** `.identity`
**Used by:** `index.html`

### Structure
```html
<section class="identity">
  <div class="identity-grid"> <!-- 2-col: text | stats -->
    <div>
      <div class="identity-label">India's Youth Newsroom</div>
      <h1>Student journalism. No filters.</h1>
      <div class="identity-divider"></div>
    </div>
    <div class="stats"> <!-- 4 stat boxes --> </div>
  </div>
</section>
```

### Inputs (from Firestore `siteConfig/hero`)
- `eyebrow` → `.identity-label`
- `headline` → `<h1>`
- `stat1Value`, `stat1Label` → first `.stat`
- (same pattern for stat2, stat3, stat4)

### Responsive
| Breakpoint | Behaviour |
|---|---|
| Desktop | 2-column grid: text left, stats right |
| ≤768px | Single column, stats become horizontal scroll row |

## Category Filter Bar

**Class:** `.filter-bar`
**Used by:** `index.html`, `stories.html`

### Structure
```html
<div class="filter-bar">
  <div class="filter-inner">
    <button class="chip active" data-cat="All">All</button>
    <button class="chip" data-cat="Campus Fraud">Campus Fraud</button>
    ...
  </div>
</div>
```

### Behaviour
- Sticky below navbar (`position: sticky; top: 57px`)
- Horizontal scroll on overflow (no scrollbar visible)
- Click sets `.active` on clicked chip, removes from others
- Triggers `renderStories()` and `renderVideos()` with new category filter
- Filtering is client-side on already-loaded data

## Field Reports Card

**Class:** `.video-card`
**Used by:** `index.html` Field Reports sidebar
**Generated by:** `renderVideoCards()`

### Structure
```html
<a class="video-card stagger" href="story.html?ytid={id}">
  <div class="video-thumb-wrap">
    <img class="video-thumb" />
    <div class="video-overlay"><div class="play-btn">▶</div></div>
    <div class="duration">11:24</div>
  </div>
  <div class="video-body">  <!-- CRITICAL: single grid child in col 2 -->
    <div class="video-tag">Field Reports</div>
    <h3 class="video-title">Title</h3>
    <div class="video-meta">views · date</div>
  </div>
</a>
```

### Layout
- CSS Grid: `112px 1fr`
- `.video-body` is `display: flex; flex-direction: column; gap: 4px; min-width: 0`
- **Critical:** `.video-body` must be a single grid child. Do not make `.video-tag`, `.video-title`, `.video-meta` direct grid children.

### Responsive
- Same grid at all viewports
- `.video-body` flex column handles stacking at all widths
- `min-width: 0` on `.video-body` prevents text overflow

## Trending Card

**Class:** `.trending-card`
**Used by:** `index.html` Trending Now section
**Generated by:** `renderTrending()`

### Structure
```html
<a class="trending-card stagger" href="story.html?id={id}">
  <div class="trending-thumb-wrap">
    <img class="trending-thumb" />
    <div class="trending-num">01</div>  <!-- rank badge, bottom-left overlay -->
  </div>
  <div class="trending-body">
    <div class="trending-tag">Category</div>
    <div class="trending-title">Headline</div>
    <div class="trending-count">214,000 reads</div>
  </div>
</a>
```

### Thumbnail resolution (in order)
1. `t.imageUrl` from Firestore trending doc
2. `allStories.find(s => s.id === t.ref_id).coverImage`
3. `picsum.photos/seed/wevox-tr{i}/480/270` fallback

### Layout
- `display: flex; flex-direction: column`
- `min-width: 240px; max-width: 240px`
- Horizontal scroll row with `scroll-snap-align: start`

## Skeleton Loaders

**Classes:** `.skeleton`, `.sk-story`, `.sk-video`, `.sk-thumb`, `.sk-line`
**Used by:** All pages with dynamic content

### Purpose
Shown immediately on page load while Firestore data is being fetched. Replaced by real content when data arrives.

### Pattern
```css
.skeleton {
  background: linear-gradient(90deg, #E8E4DF 0%, #F5F2EE 50%, #E8E4DF 100%);
  background-size: 200% 100%;
  animation: shimmer 1.5s infinite;
  border-radius: 4px;
}
```

## FAB (Floating Action Button)

**Class:** `.fab-wrap` / `#fabWrap`
**Used by:** `index.html`

### Structure
```html
<div class="fab-wrap" id="fabWrap">
  <div class="fab-options">
    <a class="fab-option" href="submit.html?type=story">📝 Write Story</a>
    <a class="fab-option" href="submit.html?type=video">🎥 Field Video</a>
  </div>
  <button class="fab" id="fab" aria-expanded="false">+</button>
</div>
```

### Behaviour
- Fixed bottom-right (`position: fixed; bottom: 28px; right: 28px`)
- Click toggles `.open` class on `.fab-wrap`
- Options fade in with stagger delay
- FAB rotates 45° when open (+ becomes ×)
- Click outside closes the FAB

## Empty / Error States

**Classes:** `.empty-state`, `.error-state`
**Used by:** All pages with dynamic content

```html
<!-- Empty state -->
<div class="empty-state">
  <strong>No stories published yet.</strong>
  Be the first.
</div>

<!-- Error state -->
<div class="error-state">Could not load content. Check connection.</div>
```

Both use dashed border, centred text, and muted colour to signal a non-critical state without alarming the user.
